■ 起動コマンド（これだけ読めば動く）
================================================================================
ターミナルを2枚使う。1枚目にバックエンド、2枚目にフロントエンド。
どちらも PowerShell。リポジトリのルートは C:\Users\liang\Documents\GitHub\test

--- ターミナル1: バックエンド (:8000) ----------------------------------------------
    cd C:\Users\liang\Documents\GitHub\test\backend
    .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000

    ※ グローバルの python には uvicorn も fastapi も入っていない。
      必ず backend\.venv の python を使うこと。素の `python -m uvicorn ...` は
      ModuleNotFoundError: No module named 'uvicorn' で落ちる。
      仮想環境を有効化してから短く書いてもよい（実行ポリシーで弾かれることがある）。
          .\.venv\Scripts\Activate.ps1
          python -m uvicorn app.main:app --reload --port 8000

--- ターミナル2: フロントエンド (:5173) --------------------------------------------
    cd C:\Users\liang\Documents\GitHub\test\frontend
    npm install          # 初回のみ
    npm run dev

--- ブラウザで開く ----------------------------------------------------------------
    http://localhost:5173/

    ※ 127.0.0.1:5173 では繋がらない。Vite は ::1 でしか待ち受けないため、
      必ず localhost で開くこと。
