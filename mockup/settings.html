Gemini API
読み込んでいます…
キーは backend/data/app.db に Fernet で暗号化して保存されます。 復号鍵は backend/.secret.key（または環境変数 TOKEN_ENCRYPTION_KEY）です。 画面に返るのはマスク済みの文字列だけで、平文を返すAPIは用意されていません。
Google 連携（カレンダー / ToDo / メール）
読み込んでいます…
client_id とシークレットが必ず対になるため、組み合わせ違いが起きません。 貼り付けた内容は保存後に消去され、どこにも残しません。
Cloud Console のコピーボタンで取得してください。手入力すると空白や記号が混入し、 Google が 401 invalid_client を返します。
外すと、連携を保ったまま反映だけを止めます。
Google Cloud Console 側の設定
  1. プロジェクトを作成する
  2. 「APIとサービス」→ ライブラリ で Google Calendar API / Google Tasks API / Gmail API を有効化する
  3. 「認証情報」→ OAuth クライアント ID を作成（種別: ウェブ アプリケーション）
  4. 承認済みのリダイレクト URI に、下の値をそのまま登録する
  5. OAuth 同意画面は「テスト」のままでよい（審査不要）。テストユーザーに自分のアカウントを追加する
取得するのは「拘束時間」「未読の重要メール件数」「期限が今日以前のToDo件数」だけです。 予定のタイトル、メールの件名や本文は取得しません。要求する権限はすべて読み取り専用です。
